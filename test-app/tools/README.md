# tools

## generate_attacker_voices.py — 공격자 대사 음성 생성기 (Cartesia · ElevenLabs)

앱은 `INTERNET` 권한이 없습니다. 참가자 음성이 기기 밖으로 나갈 수 없다는 것을 매니페스트
수준에서 보장하는 설계이므로, TTS API를 앱 안에서 부를 수 없습니다. 대신 **PC에서 미리
음성을 만들어 `assets/attacker/`에 넣고** 재생 방식을 "녹음본 재생"으로 두면 됩니다.

실험적으로도 이쪽이 낫습니다 — 참가자마다 글자·억양·길이가 바이트 단위로 동일한 자극이
되고, 네트워크 실패로 세션이 날아갈 일이 없습니다.

> 경고 음성(개입 안내)은 이 스크립트로 만들지 **않습니다.** 경고가 상대방과 비슷한 사람
> 목소리면 참가자가 경고를 "상대가 하는 말"로 오인해 개입이 사기의 일부처럼 받아들여집니다.
> 경고는 앱의 기계적인 시스템 TTS로 두는 것이 맞습니다.

### 목소리 6종

연구자가 설정 화면 ④에서 고른 목소리가 그대로 재생됩니다. 폴더가 그 선택과 1:1로
대응합니다:

```
assets/attacker/<시나리오ID>/<목소리ID>/<순번>.mp3
```

| 목소리ID | | 목소리ID | |
|---|---|---|---|
| `m20` | 20대 남성 | `f20` | 20대 여성 |
| `m30` | 30대 남성 | `f30` | 30대 여성 |
| `m40` | 40대 남성 | `f40` | 40대 여성 |

파일 이름은 개입 전 대사가 `1, 2, 3...`, 개입 후 후속 대사가 `f1, f2, f3...` 입니다.
목소리ID는 Kotlin의 `AttackerVoice` enum과 같아야 하며, 스크립트가 실행할 때마다 그
파일을 읽어 대조합니다 — 한쪽만 고치면 앱이 찾지 않는 폴더에 음성을 쌓게 됩니다.

**6종을 다 채울 필요는 없습니다.** 쓸 목소리만 준비하면 되고, 설정 화면이 어느 목소리가
준비됐는지 보여 줍니다.

### 업체 두 곳

`-p` / `--provider`로 고릅니다. 모델은 비워 두면 업체 기본값이 쓰이고, 엇갈린 조합
(`-p cartesia --model eleven_v3`)은 요청을 보내기 전에 거절됩니다.

| 업체 | 기본 모델 | 환경변수 | 100만 자당 | 특징 |
|---|---|---|---|---|
| `cartesia` (기본) | `sonic-3.6` | `CARTESIA_API_KEY` | 약 $45 | 2026년 블라인드 청취에서 **자연스러움 1위(4.36)** |
| `elevenlabs` | `eleven_v3` | `ELEVENLABS_API_KEY` | 약 $100 | 오디오 태그(`[urgent]`)로 연기 지시 |

어느 쪽이 이 대본에 맞는지는 **귀로 판단해야 합니다.** 아래 `--sample`로 같은 대사를
양쪽에서 뽑아 나란히 들어보세요 — 한 줄에 1~2센트입니다.

> Inworld는 아직 넣지 않았습니다. HTTP API 레퍼런스가 로그인 뒤에 있어 정확한 스키마를
> 확인할 수 없었습니다. 추측으로 구현하면 키를 넣는 순간 실패하므로 보류했습니다.

### 준비

Python 3.9+ 만 있으면 됩니다 (표준 라이브러리만 사용). ffmpeg는 `--telephone`을 쓸 때만
필요합니다.

```bash
$env:CARTESIA_API_KEY="..."
```

키를 `--api-key`로 넘기면 셸 기록에 남으므로 환경변수를 권합니다.

### 1) 먼저 한 줄만 들어보기

6종을 다 만들기 전에 목소리 하나를 **실제 실험 대사**로 뽑아 판단합니다. `voices.json`도
필요 없고, assets도 건드리지 않습니다.

```bash
python tools/generate_attacker_voices.py -p cartesia --list-voices
```

```bash
python tools/generate_attacker_voices.py -p cartesia --sample --voice-id <고른_id>
```

결과는 `tools/samples/sample_S1_cartesia_sonic-3.6_<id>.mp3`로 떨어집니다. 파일명에 업체와
모델이 들어가므로 여러 조합을 뽑아 한 폴더에서 비교할 수 있습니다.

읽는 문장은 기본적으로 그 시나리오의 첫 대사입니다 — 아무 인사말이나 들어보면 어떤
모델이든 자연스럽게 들려서 판단이 어긋납니다. `--only S2`로 은행 사칭 쪽도, `--sample-text`로
임의 문장도 가능합니다.

### 2) 목소리 매핑 채우기

```bash
python tools/generate_attacker_voices.py --init-voices
```

`tools/voices.json`이 생깁니다. **업체마다 voice_id 체계가 달라 칸이 따로** 있습니다:

```json
{
  "cartesia":   { "m20": "", "f20": "", "m30": "...", ... },
  "elevenlabs": { "m20": "", "f20": "", "m30": "...", ... }
}
```

연령대·성별을 보고 6칸에 배정하세요. 모델이 다국어라 한국어 표시가 없어도 한국어를
읽습니다. 비워 둔 칸은 생성 대상에서 빠집니다.

### 3) 생성

```bash
python tools/generate_attacker_voices.py -p cartesia
```

그 업체 칸에 채워진 목소리 전부 × 시나리오 2종을 만듭니다. 실행하면 **만들 파일 목록과
문자 수, 예상 비용을 먼저 보여 주고** 진행 여부를 묻습니다.

대사는 시나리오당 개입 전 + 후속을 합쳐 S1이 4줄, S2가 7줄입니다. 한 목소리당 두 시나리오
합계 약 490자이므로 **6종 전부를 만들어도 Cartesia $0.13 / ElevenLabs $0.30** 입니다.

자주 쓰는 옵션:

| 옵션 | 설명 |
|---|---|
| `-p cartesia` / `-p elevenlabs` | 업체 (기본 cartesia) |
| `--variants m30,f40` | 일부 목소리만 |
| `--only S2` | 한 시나리오만 |
| `--model <id>` | 비우면 업체 기본 모델 |
| `--emotion <값>` | Cartesia 전용. 허용값이 공개 문서에 전부 없어 기본은 보내지 않습니다 |
| `--telephone` | 300~3400Hz 전화 대역 필터 (ffmpeg 필요) |
| `--replace-existing` | 같은 순번의 예전 `.m4a` 등을 지우고 진행 |
| `--no-followups` | 후속 대사를 만들지 않음 (아래 주의 참고) |
| `--no-audio-tags` | ElevenLabs 연기 태그를 붙이지 않음 |

어조는 **시나리오별**로 정해져 있고(S1은 다급한 반말, S2는 사무적인 존댓말), 화자는
목소리ID가 정합니다. 즉 "40대 여성이 다급한 반말로" 같은 조합이 자동으로 나옵니다.
업체별로 적용 방식이 다릅니다 — Cartesia는 `generation_config.speed`, ElevenLabs는
`voice_settings.stability` + 오디오 태그.

### 4) 점검

```bash
python tools/generate_attacker_voices.py --check
```

시나리오 × 목소리 6종을 표로 보여 주고, 어긋난 것이 있으면 종료 코드 1을 돌려줍니다:

```
[S2] 개입 전 4줄 · 후속 3줄
   m30  30대 남성  ⚠ 대본과 어긋남: 1.mp3
        음성: 예전 문장입니다....
        대본: 안녕하세요. 충대은행 보안팀입니다....
   f40  40대 여성  ⚠ 개입 전 대사 3/4 — 나머지는 시스템 TTS로 나갑니다
```

대사 문구는 `AttackerScriptCatalog.kt`에서 **직접 읽습니다.** 문장을 따로 복사해 두면
대본을 고쳤을 때 음성만 옛 문장으로 남아 실험이 조용히 오염됩니다. 생성할 때 목소리 폴더마다
`manifest.json`에 어떤 문장으로 만든 파일인지 남기므로 `--check`가 그 어긋남을 찾아냅니다.

**대본을 수정했다면 반드시 `--check`를 돌리세요.**

### 주의할 점

- **목소리는 "녹음본 재생" 모드에서만 들립니다.** 다른 모드에서는 시스템 TTS가 읽으므로
  선택이 소리에 반영되지 않고, 로그에 `attackerVoiceApplied=false`로 남습니다. 설정 화면이
  이 상태를 경고로 띄웁니다.
- **한 줄이라도 비면 통화 도중에 목소리가 바뀝니다.** 앱은 빠진 줄만 시스템 TTS로 대체하고
  `attacker_line_fallback_tts` 이벤트를 남깁니다. 그 세션은 목소리 조건으로 쓸 수 없으니,
  설정 화면 ④에서 "녹음본 완비"로 표시되는 목소리만 쓰세요.
- **후속 대사(`f1...`)를 빼면 안 됩니다.** 개입 1에서 참가자가 [통화 이어가기]를 누른 직후
  듣는 것이 바로 그 대사입니다. 여기서 목소리가 기계음으로 바뀌면 참가자가 연출임을
  알아차려 그 뒤 행동이 측정값이 되지 못합니다. 그래서 기본으로 함께 만듭니다.
- 앱은 확장자를 **m4a → mp3 → wav → ogg** 순으로 찾습니다. 같은 순번에 예전 `1.m4a`가
  남아 있으면 새로 만든 `1.mp3`가 재생되지 않습니다. 스크립트가 이 상황을 감지해 멈추고,
  `--replace-existing`을 주면 지우고 진행합니다.
- 생성 후 앱을 **재빌드**해야 assets가 반영됩니다.
