공격자(상대방) 녹음본을 넣는 폴더입니다. (재생 모드 "녹음본 재생"에서 사용)

구조
  attacker/<시나리오ID>/<대사 순번>.<확장자>

  예) 시나리오 1(S1)의 대사 5줄을 녹음했다면
      attacker/S1/1.m4a
      attacker/S1/2.m4a
      attacker/S1/3.m4a
      attacker/S1/4.m4a
      attacker/S1/5.m4a

시나리오 ID
  S1 = 지인          (급전 요구, 대사 5줄)
  S2 = 모르는 사람   (은행 사칭, 대사 4줄)

규칙
- 순번은 대본에 적힌 대사 순서 그대로 1부터 셉니다.
  정확한 번호와 문장은 앱의 연구자 패널 > ② 대본 진행에서 확인할 수 있습니다.
- 개입 이후에 쓰는 후속 대사는 녹음본을 쓰지 않습니다(항상 TTS로 나갑니다).
- 지원 확장자: m4a, mp3, wav, ogg (이 순서로 탐색)
- 파일이 없는 대사는 자동으로 TTS로 대체되고, 그 사실이 세션 로그에
  attacker_line_fallback_tts 이벤트로 남습니다. 요약의 ttsFallbackCount로도 보입니다.
- 대사 한 줄 = 파일 한 개로 나눠 녹음해야 개입 발동 시점이
  참가자마다 정확히 동일해집니다. 통짜 파일 한 개는 지원하지 않습니다.
- S1(지인)은 편한 반말로, S2(모르는 사람)는 사무적인 존댓말로 녹음하세요.
  두 시나리오의 차이는 "아는 사람으로 보이는가" 하나뿐이므로 어조가 그 차이를 만듭니다.
